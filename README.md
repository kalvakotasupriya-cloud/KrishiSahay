🌾 KrishiSahay – Smart Agriculture Assistant

KrishiSahay is an AI-powered agriculture assistant designed to help farmers access useful farming information quickly and easily. The application allows users to ask agriculture-related questions, detect plant diseases from leaf images, and receive guidance about crops and farming practices.

The system supports both online and offline modes, making it useful even in areas with limited internet connectivity. When internet is available, the assistant can use AI services for enhanced responses. When offline, it relies on locally stored data and machine learning models to continue providing support.
